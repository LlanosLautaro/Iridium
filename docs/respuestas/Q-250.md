# Q-250 — Probá los comandos con «/» en el chat

- [x] Escribir «/» abre la lista arriba del cuadro, con los comandos y para qué sirven; los de un complemento dicen de cuál a la derecha
- [x] Escribir después de «/» filtra (`/review` encuentra `/code-review`); las flechas y Enter eligen, y elegir no manda: queda «/nombre » para escribirle algo
- [x] Mandar un comando que sirve en Iridium (`/compact` o `/iridium:iridium`) funciona: en el chat se ve el comando en la letra de los códigos y la respuesta debajo
- [x] Volver a escribir «/» muestra arriba «Usados hace poco»
- [x] Escribir `/clear` o `/model` a mano no se manda: una línea arriba del cuadro dice dónde está eso en Iridium (con `/clear`, el botón Nueva)
- [x] El + del pie del cuadro tiene «Comandos», que escribe la «/» y abre la lista
- [x] Al reabrir esa conversación desde ◔, el comando sigue viéndose como comando
