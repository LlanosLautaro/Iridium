# Q-270 — Instalá Iridium 1.0.0 en la otra PC con el instalador

- [x] Cerrar Iridium (si quedó abierto en negro, desde el Administrador de tareas)
- [x] Bajar `Iridium-Setup-1.0.0.exe` de la versión `v1.0.0` (la de arriba) en github.com/LlanosLautaro/Iridium/releases
- [x] Abrirlo; si Windows dice «Windows protegió su PC»: Más información › Ejecutar de todas formas. Se instala solo y abre Iridium
- [x] Iridium abre normal, con los proyectos de siempre (o muestra «Iridium no pudo mostrar esta pantalla»: anotá el texto)
- [x] Hay un acceso «Iridium» en el escritorio y en el menú Inicio
- [x] Borrar la carpeta vieja de Iridium (la que tiene `win-unpacked`) y su acceso directo viejo
- [x] Si sigue en negro: dejar en Otro el archivo más nuevo de `%APPDATA%\Centro de Desarrollo\registros\`

> Procesada el 2026-11-24 → CO-I10 hecha (`modulos/compartir/estado.md`)
