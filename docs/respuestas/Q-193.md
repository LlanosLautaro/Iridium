# Q-193 — ¿Qué es el Mapa: una hoja de ruta, una red de pasos o un kanban?

**Respuesta (en el chat):** hagamos maquetas. El kanban queda descartado. La red de pasos no: se puede seccionar por frente, cada frente con un camino de pasos, ramas cuando las haya y el foco siempre cerca del último completado. La opción A también queda. Pensaba más en algo tipo red porque es secuencial (paso 1, luego 2, luego 3) en lugar de solo acumular cosas en un estado.
