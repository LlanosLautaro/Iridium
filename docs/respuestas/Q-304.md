# Q-304 — ¿Cómo dejamos de tener problemas con las actualizaciones?

**Opción:** A) Tu Iridium también instalado, con el mismo instalador y la misma actualización que la otra PC: un solo camino para mantener y probar, el estándar de Windows (el instalador cierra a la fuerza todo Iridium antes de copiar), y tu app fuera de la carpeta del código, donde las pruebas de la IA no la tocan.
