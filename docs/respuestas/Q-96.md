# Q-96 — Mirar los archivos de una skill

- [x] Al elegir una skill, debajo de su nombre está el árbol con **Resumen** marcado (avisos y descripción, como antes) y sus archivos.
- [x] Tocando `SKILL.md` o un archivo de `references`, se lee a la derecha, con números de línea y «solo lectura».
- [x] Al pasar a otra skill y volver, sigue en el archivo que mirabas.
- [ ] ¿Algo que cambiarías? Por ejemplo: las líneas largas no se cortan (se desplaza de costado), como en Archivos; si preferís que en los `.md` se corten, o que se lean con formato como en Docs, decilo.
