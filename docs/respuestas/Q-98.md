# Q-98 — Elegir la carpeta de proyectos

- [x] Ajustes (⚙ o `Ctrl+,`) › Proyectos muestra tu carpeta de proyectos.
- [x] **Cambiar…** abre el cuadro de Windows en esa carpeta; Cancelar no cambia nada.
- [x] Elegí otra carpeta (por ejemplo, una vacía): la grilla cambia en el acto. Volvé a elegir la carpeta de proyectos y todo sigue como estaba.
- [ ] ¿La sección y el nombre «Proyectos» te cierran, o la pondrías en otro lado?
