# Q-292 — Probá usar la PC

- [x] «Usar la PC» dice «Windows-MCP · falta instalarlo» y el interruptor no se prende
- [x] Instalar abre la consola de abajo (primero «Instalar uv», después «Instalar Windows-MCP»; si Windows pide permiso, aceptalo) y al terminar la fila dice «Windows-MCP, instalado» con el interruptor prendido
- [x] En una conversación nueva, pedile «sacá una captura de la pantalla y decime qué programa está adelante»: el paso dice «En la PC: sacó una captura» y la IA contesta bien
- [x] Apagás «Usar la PC», abrís otra conversación nueva y la IA ya no puede sacar la captura
