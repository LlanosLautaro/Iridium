# Q-251 — Probá los archivos y las fotos en el chat

- [x] El + del pie tiene «Agregar archivos o fotos» (y `Ctrl+U` en el cuadro): abre el selector de Windows y se pueden elegir varios; cada uno queda como ficha arriba del cuadro (la foto como miniatura, el archivo con su nombre) — cambia el icono de adjuntar por un clip
- [x] Arrastrar archivos desde el explorador sobre la conversación la marca con un borde punteado y «Suelta para adjuntar»; al soltarlos se suman
- [x] Una captura copiada (`Win+Shift+S`) y pegada con `Ctrl+V` en el cuadro queda como foto
- [x] Un clic en una foto la abre grande; `Esc` la cierra. La ✕ de una ficha la saca
- [x] Cambiar de proyecto o cerrar Iridium no pierde las fichas
- [x] Al mandar, la IA ve la foto y abre el archivo; en tu mensaje quedan las fichas arriba de lo escrito, y siguen al reabrir la conversación desde ◔
- [x] Un clic en un archivo de un mensaje mandado lo abre (si es del proyecto, en Archivos)
