# Q-258 — Probá el texto largo pegado en el chat

- [x] Pegar un texto largo con `Ctrl+V` no llena el cuadro: queda como ficha «Texto pegado · N líneas» arriba
- [x] Un clic en la ficha lo abre para leerlo; `Esc` lo cierra. La ✕ lo saca
- [x] `Ctrl+Z` justo después de pegar lo deja como texto en el cuadro, donde estaba el cursor
- [x] Un texto corto se pega en el cuadro, como siempre
- [x] Al mandar, en tu mensaje queda la ficha arriba de lo escrito (se abre con un clic), y sigue al reabrir la conversación desde ◔
- [x] «Hablar de esta idea» (Ideas) y «Sobre la skill …» (Skills) se ven como fichas con su ícono, en la misma fila que los adjuntos
