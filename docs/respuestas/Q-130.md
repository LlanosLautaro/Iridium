# Q-130 — Probá Eliminar desde el clic derecho

- [x] Clic derecho en su tarjeta › **Eliminar…** abre la confirmación con cuántos archivos van a la papelera
- [x] **Cancelar** (o Esc) no toca nada
- [x] **Eliminar** saca la tarjeta y el aviso dice que está en la papelera
- [x] La carpeta está en la papelera de Windows y **Restaurar** la devuelve a la grilla
