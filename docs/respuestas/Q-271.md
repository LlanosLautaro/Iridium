# Q-271 — Probá el sonido de Iridium al terminar

- [x] En Ajustes › Notificaciones, tocar cada sonido (Campana, Dos notas, Gota, Acorde) lo hace sonar; dejar el que más te guste
- [x] Al mandar un mensaje no suena nada ni aparece un aviso de Windows
- [x] Cuando la IA termina, suena una vez el elegido, sin aviso de Windows
- [x] Si la IA deja pruebas corriendo de fondo, no suena hasta que vuelve y termina
- [x] Con el sonido apagado en Notificaciones, no suena
- [x] En VS Code, Claude Notifier no aparece en Extensiones
